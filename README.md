Análise de Dados com Python

Notebook Jupyter com exercícios práticos de análise de dados usando Python, desenvolvido como parte do meu estudo hands-on da linguagem.

🎯 Objetivo

Praticar manipulação, limpeza e análise de dados, aplicando conceitos de programação Python em um contexto real de dados.

🛠️ Tecnologias utilizadas

- Python;
- Jupyter Notebook;
- Pandas.

📌 Status

Projeto de estudo — parte da minha trilha de aprendizado em Python.
